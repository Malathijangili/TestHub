# 🍴 TasteHub – Restaurant Menu & Shopping Cart

**TasteHub** is a modern, responsive restaurant menu and shopping cart web application built using **HTML5, CSS3, and Vanilla JavaScript**.

It allows users to browse food categories, search for dishes in real time, filter food based on dietary preferences, add items to a persistent shopping cart, manage quantities, and complete a simulated checkout.

🔗 **Live Demo:**  
https://malathijangili.github.io/TestHub/

---

## 🌟 Features

- 📱 **Fully Responsive Design**
  - Desktop
  - Tablet
  - Mobile

- 🍔 **Dynamic Category Filtering**
  - All
  - Starters
  - Main Course
  - Pizza
  - Burgers
  - Desserts
  - Drinks

- 🔍 **Real-Time Search**
  - Search by food name
  - Search by description
  - Search by category

- 🥬 **Dietary Filtering**
  - Veg
  - Non-Veg

- 🛒 **Interactive Shopping Cart**
  - Add items to cart
  - Increase/decrease quantity
  - Remove items
  - Dynamic cart counter
  - Slide-in cart drawer

- 💰 **Dynamic Price Calculation**
  - Subtotal
  - 5% tax
  - Final total

- 💾 **LocalStorage Persistence**
  - Cart remains available after refreshing the page
  - Cart data is stored in the browser

- 💳 **Simulated Checkout**
  - Checkout confirmation modal
  - Cart automatically cleared after checkout

- 📧 **Contact Form**
  - Form validation
  - User feedback
  - Toast notifications

- 🎨 **Modern UI**
  - Glassmorphism effects
  - Smooth animations
  - Hover effects
  - CSS variables
  - Responsive layouts
  - Sticky navigation
